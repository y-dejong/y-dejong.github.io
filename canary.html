Canary

Monitoring and Control System for DMX/RDM and Art-Net lighting fixtures

Download for Linux x64

Manage your entire set lighting system across wired, wireless, and multiple protocols from one seamless web interface

Features:

  • Plug and play functionality: Plug the device running Canary into your network, and let it discover fixtures automatically
  • Manage Art-Net universes, DHCP, and IP configurations remotely
  • Read and Set RDM properties like DMX address and profile
  • Quickly recognize when a device disconnects from the network
  • Currently supported protocols: DMX, RDM, Art-Net (Wi-Fi or wired)
  • See your configuration from any device connected to the network through the web interface

Planned Features:

  • Support for cRMX, sACN, Sidus Link, and Bluetooth protocols
  • Eventual integration with smart home protocols like Thread, Matter, and Zigbee
  • Hardware device to attach to networks over multiple physical interfaces
  • Auto syncing of device configurations
  • Notifications on disconnect
